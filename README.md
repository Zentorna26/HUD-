# HUD+

**HUD+** — планшет у стилі iPad, який відкривається поверх GTA 5 RP однією клавішею. Біндер, законодавство сервера, калькулятор штрафів, нотатки, Discord і фоновий запис гри — усе в одному місці, без згортання гри.

> Програма для Windows 10 / 11 (64-біт). Працює з NG та іншими серверами на RAGE / alt:V / FiveM-подібних клієнтах.

---

## 📥 Встановлення

1. Відкрий **[Releases](../../releases/latest)** і завантаж файл `HUD-Plus-Setup-….exe`.
2. Запусти його. Права адміністратора не потрібні — програма ставиться лише для твого користувача.
3. Якщо Windows покаже синє вікно **«Windows захистила ваш ПК»** — натисни **«Докладніше» → «Виконати все одно»**.
   Це звичайне попередження для програм без платного цифрового підпису.
4. Після встановлення HUD+ з'явиться в треї (біля годинника) і на робочому столі.

## 🔑 Перший запуск

1. Натисни **F10** — відкриється планшет.
2. **Увійти через Discord** — відкриється твій браузер, натисни там «Авторизувати». Планшет відкриється сам.
3. *(необов'язково)* **Налаштування → Акаунт → Сервер Discord** — вибери сервер своєї фракції чи сім'ї: звідти підтягнеться твій нік.

HUD+ отримує від Discord лише твій нік, аватар, список серверів і ролі на вибраному сервері. Пароль і повідомлення програма не бачить.

## 🧩 Що всередині

| Застосунок | Що вміє |
|---|---|
| **Біндер** | Бінди на клавіші, набори для різних ролей, кругове меню (за замовчуванням `` ` ``), картинки поверх гри, змінні `{ім'я}` `{жетон}` `{час}` (за Києвом) і `{вибір: …}`, обмін наборами за кодом, імпорт з binder-bot. Вставка відіграшу з кількох рядків — кожен рядок стає окремим рядком бінда |
| **Законодавство** | Усі закони сервера з пошуком, вибрані статті, окрема клавіша для швидкого пошуку |
| **Штрафи** | Калькулятор стягнень за статтями АК і КК з урахуванням лімітів |
| **Нотатки** | Нотатки, які можна закріпити поверх гри |
| **Discord** | Discord прямо в планшеті |
| **Записи** | Фоновий запис гри (як у Steam): останні 60 хв завжди під рукою, перегляд без збереження, обрізка, збереження в MP4 |
| **Налаштування** | Теми, шпалери, звуки, клавіші, оверлей, оновлення |

## ⌨️ Клавіші за замовчуванням

| Клавіша | Дія |
|---|---|
| `F10` | Відкрити / закрити планшет |
| `` ` `` (тильда) | Кругове меню біндів |
| `Alt+Q` | Кругове меню HUD+ (бінди, запис, скрін, застосунки) |
| `End` | Зупинити бінд, що відтворюється |
| `Alt+F9` | Зберегти останні 3 хв запису |
| `Alt+F12` | Скріншот гри |
| `Esc` | Назад / закрити |

Усі клавіші змінюються в налаштуваннях (Планшет, Біндер, Записи).

## 🎯 Кругове меню HUD+
Натисни `Alt+Q` у грі — посеред екрана з'явиться меню з двох кілець. Наведи мишку на розділ (Бінди, Записи, Скріншот, Закони, Штрафи, Нотатки, Планшет) — зовні з'являться його дії: зберегти 1/3/5 хв запису, увімкнути чи вимкнути набір біндів, відкрити Discord тощо. Клік — виконати, `Esc` — закрити. Клавішу можна змінити або вимкнути меню в Налаштуваннях → Планшет.

## 🔗 Обмін біндами
- **Поділитися:** Біндер → відкрий набір → кнопка ⬆ → отримаєш код з 6 символів (він одразу копіюється).
- **Додати:** Біндер → «Додати за кодом» → встав код → Enter. Набір додається вимкненим — перевір клавіші й увімкни.
- Картинки з біндів передаються разом із кодом. Щоб поділитися, потрібен вхід через Discord.

## 🎥 Фоновий запис

- Увімкни в застосунку **«Записи»**. Запис іде лише поки запущена гра.
- **Звук «Лише гра»** — на записі тільки гра: без Discord, музики й браузера (потрібна Windows 10 2004 або новіша).
- **Мікрофон «Лише по клавіші»** — твій голос пишеться тільки поки затиснута клавіша рації (та сама, що в грі).
- Якість до **1440p 60 к/с**, кодує відеокарта — на FPS майже не впливає.
- Буфер на 60 хв займає 3,5–13 ГБ залежно від якості. Папку можна змінити.
- Якщо на записі чорний екран — у налаштуваннях запису вибери «Весь екран».

## 🔄 Оновлення

HUD+ сам перевіряє оновлення при запуску і кожні 6 годин. Вручну: **Налаштування → Про планшет → Перевірити оновлення**.
Нова версія завантажується і встановлюється однією кнопкою — бінди, нотатки й налаштування зберігаються.

## ❓ Часті питання

**Бінди не друкуються в грі.**
Перевір у **Біндері**, що гра визначилась («Гра: …»). Якщо ні — натисни «Додати» поруч зі списком процесів гри, коли гра відкрита.

**Планшет не відкривається на F10.**
Клавіша могла бути зайнята іншою програмою — зміни її в **Налаштування → Планшет**.

**Не вдається увійти через Discord.**
Перевір, що HUD+ запущений (іконка в треї), і що порт `53134` не зайнятий іншою програмою. Спробуй ще раз.

**Чи безпечно це для акаунта в грі?**
HUD+ не змінює файли гри і не читає її пам'ять — лише натискає клавіші й вставляє текст, як звичайний біндер. Але правила щодо біндерів і стороннього ПЗ на кожному сервері свої — перевір їх перед використанням.

**Як видалити?**
**Параметри Windows → Програми → HUD+ → Видалити.** Налаштування лишаються в `%APPDATA%\HUD+` — видали цю папку, якщо треба прибрати все.
